# Student Performance Prediction using Machine Learning

### Project Overview

This is an individual project completed for the SP452 Machine Learning course at the University of the Thai Chamber of Commerce (UTCC).

The project uses a student performance dataset from Kaggle to explore factors such as GPA, study time, and absences, and compares Machine Learning models for predicting student grade categories.

### Technologies & Tools

- **Programming Language:** Python
- **Libraries:** Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn
- **Development Tools:** Google Colab, Google Drive
- **Dataset:** Student Performance Dataset from Kaggle

### My Work

- Explored the dataset, checked for missing values, and analyzed student performance factors using charts.
- Prepared the features and target variable, then split the dataset into training and testing sets.
- Trained four Machine Learning models: Logistic Regression, Decision Tree, Random Forest, and Support Vector Machine (SVM).
- Compared model performance using accuracy scores, classification reports, and confusion matrices.

### Results

Random Forest achieved the highest accuracy of **91.23%** on the test dataset.

The results showed that Random Forest performed best among the four models, although some grade categories were harder to predict due to differences in the number of samples.
